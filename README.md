TIỆM ĐỒ CŨ TRUNG KYEN

Website mua bán đồ cũ dành cho sinh viên

1. Giới thiệu dự án

Tiệm Đồ Cũ Trung Kyen là website hỗ trợ sinh viên mua bán và trao đổi các sản phẩm đã qua sử dụng với mức giá tiết kiệm.

Website cung cấp thông tin sản phẩm, hình ảnh thực tế, tình trạng sử dụng và giá bán để người mua dễ dàng lựa chọn.

2. Mục tiêu dự án

Xây dựng website mua bán đồ cũ đơn giản, dễ sử dụng.

Giúp sinh viên tiết kiệm chi phí mua sắm.

Tạo môi trường trao đổi và thanh lý đồ dùng sinh viên.

Thực hành kiến thức HTML và CSS.

3. Công nghệ sử dụng

| Công nghệ | Mục đích sử dụng |
|---|---|
| HTML5 | Xây dựng cấu trúc và nội dung website |
| CSS | Thiết kế giao diện và phối màu |
| Visual Studio Code | Viết và chỉnh sửa mã nguồn |
| GitHub | Lưu trữ và quản lý mã nguồn dự án |
| Google Chrome | Kiểm tra và chạy thử website |

4. Các chức năng chính

Hiển thị danh sách sản phẩm thanh lý.

Hiển thị hình ảnh và thông tin sản phẩm.

Hiển thị giá bán và giá cũ.

Hướng dẫn quy trình mua hàng.

Form liên hệ đặt giữ hàng hoặc ký gửi đồ cũ.

Điều hướng nhanh giữa các khu vực trên website.

Giao diện tương thích với máy tính, máy tính bảng và điện thoại.

6. Hướng dẫn chạy website

Tải hoặc clone mã nguồn dự án về máy.

Mở thư mục dự án bằng Visual Studio Code.

Kiểm tra thư mục css và assets.

Mở file index.html.

Sử dụng tiện ích Live Server để chạy website trên trình duyệt.

7. Đối tượng sử dụng

Sinh viên có nhu cầu mua đồ cũ giá rẻ.

Sinh viên muốn thanh lý đồ dùng không còn sử dụng.

Người có nhu cầu tìm kiếm sản phẩm đã qua sử dụng.
